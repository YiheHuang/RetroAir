
本提交包已经包含 ResMLP 部署模型和推理标准化器，因此无需重新训练即可启动 Web 界面。

## 从零复现数据与训练流程

如需从原始数据重新构建数据集，需要先复制环境变量模板并填写 Copernicus ADS API Key：

```bash
cp .env.example .env
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

其中 CAMS EAC4 AOD 数据下载需要：

1. 注册 Copernicus Atmosphere Data Store 账号。
2. 获取 ADS API Key，并填写到 `.env` 的 `ADS_API_KEY`。
3. 在 ADS 网页端接受 `cams-global-reanalysis-eac4` 数据集许可。

然后可按 README 中的流程执行：

```bash
python scripts/00_build_dataset.py --start-year 2018 --end-year 2025 --city 北京
python scripts/05_merge_to_final.py --input "data/processed/merged/merged_2018_2025_*.csv" --out data/processed/final/merged_8_cities_2018_2025.csv
python scripts/06_compare_algorithms.py
```

## 说明

提交包未包含全量原始数据和 CAMS NetCDF 缓存，以控制体积；相关数据可通过脚本和公开 API 重新获取。若本地尚未下载 CAMS NetCDF，应用仍可加载模型并运行，但完整 AOD 特征推理建议按上述步骤配置 ADS Key 并下载对应年份数据。
